# SignBridge VRM Demo 关键攻坚 - Verification Checklist

## 初始姿态
- [ ] 页面加载完成后，虚拟人呈自然站立姿态
- [ ] 双臂自然下垂于身体两侧，而非 T-pose 平举
- [ ] 肘部微屈（约 10-15°）

## 动画播放与归位
- [ ] 输入"你好"点击播放，挥手动作基本可辨识
- [ ] 动画播放完成后，手臂平滑回归身体两侧（0.3-0.5秒过渡）
- [ ] 动画结束后无 T-pose 闪现
- [ ] 多词连续播放（如"你好谢谢再见"）词间过渡自然，无 T-pose

## 核心手语词
- [ ] "你好"动作：挥手/招手基本可辨识
- [ ] "谢谢"动作：双手合十/抱拳基本可辨识
- [ ] "再见"动作：挥手基本可辨识
- [ ] 手部不严重穿入身体

## 代码质量
- [ ] `npx tsc --noEmit` 无类型错误
- [ ] `npm test` 所有测试通过
- [ ] `npm run build` 生产构建成功
- [ ] CHANGELOG.md 已更新
- [ ] 2D/skeleton 模式动画播放不受影响
